# 🌾 FIELDOPS AI

Agriculture Decision Intelligence — Multimodal Multi-Agent AI Hackathon MVP.

## Core workflow

Perceive → Retrieve → Calculate → Reason → Validate → Recommend → Report

## Features

- Streamlit field assessment dashboard
- Crop, growth-stage, soil, rainfall and weather inputs
- Specialist-agent style workflow
- Groq LLM coordinator/reasoning layer
- Controlled agriculture RAG knowledge base
- Deterministic irrigation calculation
- Preliminary crop-health/image screening boundary
- Validation and uncertainty display
- Downloadable field report
- GitHub-ready project structure

## Run locally

```bash
python -m venv .venv
# Windows:
.venv\Scripts\activate

pip install -r requirements.txt
```

Create `.env` from `.env.example` and add your Groq API key.

```bash
streamlit run app.py
```

## Streamlit Cloud

1. Push this repository to GitHub.
2. Create a Streamlit Community Cloud app.
3. Select `app.py`.
4. Add `Gemini_api` under Secrets.
5. Deploy.

## Demo scenario

Use:
- Crop: Wheat
- Growth stage: Flowering
- Area: 2 acres
- Soil moisture: 220
- Recent rainfall: 3 mm
- Expected rainfall: 2 mm
- Temperature: 30°C

The controlled demo should produce a high water-stress risk and an irrigation recommendation.

## Responsible AI

This prototype is decision support, not autonomous farm control. Image analysis is preliminary screening only. Quantitative irrigation output is generated by a deterministic Python tool using declared demo rules. Consequential field actions require human review.
